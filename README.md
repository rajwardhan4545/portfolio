## ✨ About

A **premium, animated developer portfolio** built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, just clean performant code.

Designed with inspiration from Adrian Hajdin's 3D portfolio, featuring a dark aurora aesthetic, interactive components, and a cinematic feel throughout.

---

## 🚀 Features

| Feature | Details |
|---|---|
| 🌌 **Animated Background** | Full-page canvas with 160 twinkling star-dust particles + 5 floating color orbs |
| 🛸 **Shooting Meteors** | Periodic diagonal meteor streaks across the page |
| ♾️ **Infinity Tech Marquee** | Infinite-scroll strip of 12 tech stack logos (pauses on hover) |
| 🔢 **Animated Stat Counters** | Numbers count up with easing when scrolled into view |
| 💻 **Interactive Code Editor** | 4-tab VS Code-style editor with syntax highlighting |
| 🖥️ **Terminal Emulator** | Fully functional CLI — type `whoami`, `skills`, `coffee` and more |
| 📋 **Copy Code Button** | One-click clipboard copy for any code snippet |
| 🌐 **Project Filtering** | Filter projects by category (Web, Android, Backend) |
| 📬 **Real Contact Form** | Powered by Formspree — messages go straight to inbox |
| 🖱️ **Cursor Glow Spotlight** | Ambient cursor trail that follows mouse movement |
| 📊 **Scroll Progress Bar** | Top progress indicator for page scroll position |
| 📱 **Fully Responsive** | Works on all screen sizes — mobile, tablet, desktop |
| ♿ **Accessible** | Semantic HTML, ARIA labels, keyboard navigable |

## 🛠️ Tech Stack

**Languages & Frontend**
- HTML5, CSS3 (Custom Properties, Animations, Grid, Flexbox)
- Vanilla JavaScript (ES6+, Canvas API, IntersectionObserver, Fetch API)

**External Resources**
- [Font Awesome 6](https://fontawesome.com/) — Icons
- [Google Fonts](https://fonts.google.com/) — Plus Jakarta Sans, Inter, JetBrains Mono
- [Formspree](https://formspree.io/) — Contact form backend

**Deployment**
- [Vercel](https://vercel.com/) — Zero-config static hosting


## 🏃 Run Locally

No build step needed — it's plain HTML!

```bash
# Clone the repo
git clone https://github.com/rajwardhan4545/portfolio.git

# Navigate into the folder
cd portfolio

# Open in browser (or use Live Server in VS Code)
open index.html
```

> 💡 For the best experience, use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension.

---

## 🌐 Deploy on Vercel

1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import `portfolio` repo
4. Click **Deploy** — no build settings needed!
